# Git lab: simple Python calculator with power

Simple calculator for the Git lab.

Author: Liliia Smirnova

## Functions

All functions take two numbers: integers (`int`) or decimals (`float`).

| Function | What it does | Example |
| --- | --- | --- |
| `add(a, b)` | sum of a and b | `add(2, 3)` → `5` |
| `sub(a, b)` | difference a − b | `sub(5, 3)` → `2` |
| `mul(a, b)` | product a × b | `mul(2, 4)` → `8` |
| `div(a, b)` | division a / b; returns `None` if b = 0 | `div(8, 2)` → `4.0` |
| `pow_(a, b)` | a raised to the power b | `pow_(2, 3)` → `8` |
